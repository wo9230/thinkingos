## 2. 证据账本（`C-03` 可反证）

| 陈述 | 类型 | 出处 | 置信度 |
|---|---|---|---|
|  | 事实 / 证言 / 推断（注明提出者） / 估算 / 自我标签 / 来源方假设 / 经验法 / 外部案例 / 外部信号 / 未知 |  |  |

> 分型判据：
> - **事实** = 可被第三方核对的（数字、日期、发生过的事）
> - **证言** = 某人对所见所闻的陈述；记录说话者与时间，不自动当成事实
> - **推断** = 某人从已知材料得出的解释；记录提出者与所依据的证据
> - **估算** = 基于假设的近似、预测或区间；记录假设、方法与日期，不当成已发生事实
> - **自我标签** = 对自己能力或性格的概括——不是事实，是待验证命题
> - **经验法** = 「这类情况一般会怎样」——有适用边界，必须问清边界
> - **外部信号** = 有时效，必须写日期；过期后不能继续当当前证据
