# ThinkingOS 产品宪法

**状态**：Phase 0 已接受
**适用范围**：ThinkingOS V0.1 及其后所有版本，除非有已记录的产品决策明确修订某条规则
**产品身份**：ThinkingOS 是面向决策智能（Decision Intelligence）的案例式认知运行时（case-based cognitive runtime）。其价值单元是一个真正进入现实、行动与复盘的 `ThinkingCase`，而不是一个令人印象深刻的答案。

> **当前 v0.1 执行范围**：Decision Log `D-023` 对 `C-08` 作形态例外；`D-024` 对 `C-05`、`C-06` 作临时执行例外；`D-025` 将 `C-01` 的显式 Success Contract 与 `C-02` 的强制 Triage 延后到正式收束、落盘、验证或重大事项确认不可逆承诺之前。GPT Work 中仍保留目标主权与风险边界，可先给可逆的临时保护动作，但不以表单阻塞自由探索。v0.2 North Star 仍按下列原文执行。

## 不可妥协的铁律

### C-01 — Case Owner 的目标拥有最高主权

`Case Owner` 通过成功契约（Success Contract）定义所要的结果、可观察成功标准、可接受及不可接受的投入与代价、非目标或失败条件，并拥有最终承诺。`Advisor` 的默认目标——包括增长、收入、速度、地位或方法纯度——不得在未明说的情况下取代它；任何冲突都必须被显示，并由 `Case Owner` 裁决。

### C-02 — 建议之前必须先分流

每个模糊或后果重大的输入都从清晰度分流（Clarity Triage）开始。ThinkingOS 必须先确认这是谁的决策、需要改变什么现实、利害何在，以及下一步最应进入完整 `ThinkingCase`、先补证据、先做小型可逆行动、无需框架直接解决，还是因 blocker 当前无法继续，然后才能给出与该路由相符的处理。

### C-03 — 每个重大判断都必须可反证

事实、证言、推断、估算与未知必须保持可区分。任何重大结论——无论来自人类 `Advisor` 还是 `Copilot`——都必须陈述证据、置信度、最强反方，以及什么观察会改变该结论。

### C-04 — 不得压平语境

建议必须保留会改变其有效性的语境：暖关系与冷关系、`Case Owner` 所处阶段与竞品阶段、未解问题（Unresolved Issues），以及 `Advisor` 的激励。类比是待验证的假设，不是复制行为的授权。

### C-05 — 表示同意不等于理解

“明白”、“对”或“OK”等赞同语言不能通过决策 Gate。在计划被承诺之前，`Case Owner` 必须用自己的话复述（Teach-back）问题、选择、权衡、门槛和改变判断的条件，并且可以拒绝或修改任何部分。

### C-06 — 计划是面向现实的实验

当工作确实可并行时，计划可以包含并行轨道（Parallel Tracks），不得被强塞进虚假的串行顺序。`Track Gate` 必须显式；涉及度量时，必须由有来源、可修订且经 `Case Owner` 采纳的参数化 `Threshold` 支持。`Lifecycle Gate` 必须有显式 Contract 与证据，但不必数值化。至少一个当下行动（NOW Action）必须有负责人、承诺、观察窗口与停止/继续条件。

### C-07 — 不确定性必须持久可见；学习必须靠证据赚得

未解问题在被证据或明确决策解决之前必须一直可见。学习来自将推理过程与预测、行动及结果（Outcome）对照的诊断；它不得奖励单纯复述 `Advisor` 的答案，也不得在结果已知后反向改写原判断。

### C-08 — 范围纪律本身就是产品能力

V0.1 先以专家副驾（Expert Copilot）形态服务一个真实 Case，因为这是最小可信的验证路径，而不是因为它是永久产品形态。V0.1 不得依赖新 UI、被复制的 framework kernel、多 Agent 编排、全领域覆盖、自主高风险执行，或完整认知历史平台。

## 执行约束

- 任何违反上述规则的需求、设计、评估或实现，默认拒绝。
- 例外必须有一条 Decision Log 记录，点名受影响的规则、证据、负责人、到期或重访条件，以及回滚路径。
- 当前 v0.1 施工以 `MVP-v0.1.md`、`D-024`、`D-025` 与 `D-026` 为准；其中 D-026 是专门知识的调用合同，不构成宪法例外。这些版本化执行规则不改写上述宪法长期规则，也不得被外推为 v0.2 的默认行为。
- 只交付一份精美报告、却没有已承诺行动和复盘契约，不算完成 `ThinkingCase`。
