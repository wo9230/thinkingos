# 采访引擎：把空白问出来（按需读）

> 何时读：用户说「采访我 / 建档 / 帮我填某份说明书」；事实库某页的空白挡住了当前判断；适配器（`adapt.md`）交来一份空白清单。

## 目标

没有外部模板时，默认产物结构是 `templates/intake-pack.md`（事实底稿 / 三数核算 / 方向假设清单 / 原始数据清单 / 自检与复盘）。以本人原话和数字填满一个**目标产物**（事实库某页、外部模板的某几节、一份 Case 的事实段）。产物字段齐了或本人喊停即结束。不是访谈流程本身，产物才是目的。

## 准备

1. 先复用本轮材料。用户要求使用事实库或建档时才读 `_private/facts/INDEX.md` 和相关页；空白清单仅取当前目标涉及的部分。**已有的不问。**
2. 只列目标产物缺失且影响判断的字段，按「挡住什么」排序。
3. 沿用本轮沟通偏好；确需既有个人偏好且读取已获准时，再读对应段。

## 出题：由八环生成，不用固定问卷

- 对目标产物先定**首个断点环**（见 CATALOG 路由第 1 步）：说不清要什么 → ①框定；说得出目标但事实模糊 → ②事实；有事实不知为何如此 → ③因果……只在该环出题，不越环。
- 一组最多 3 问，等答完再出下一组。可以顺着对方的话走，不按清单顺序。
- 每问只要一种答案形态：一个数字、一个时间点、或一件具体的事。

## 追问纪律

- 笼统答复（「还行」「看情况」「就是做 X 的」「挺多的」）→ 追到具体：多少、什么时候、哪一次。
- 独特资源、优势、差异化 → 必须挂一个真实例子；形容词不算答案。
- 「我觉得 / 应该 / 大概」→ 标记为本人推断，不升级为事实。
- 答不上来 → 标 `〔空白〕`，任务包含事实库维护时才登记到 `04` 页；**绝不替本人补写**。
- 与事实库已有内容或本轮前文冲突 → 当面指出两处说法，记 `⚠`，请本人裁决；不静默取一边。
- 不给建议、不夸、不把答复总结成漂亮话；本人要求时才转回分析。

## 写回

- 任务明确包含建档或事实库更新，且本人确认要保存的内容后，才追加到相关页「证据轨迹」。本人口述标 🟢；本人审议确认才标 🏆，模型推断不升级为事实。仅采访、填稿或分析时先在当前产物保留来源，不自动落库。
- 页顶部「当前最佳理解」只在本人确认后改写；数字改动要写旧值→新值。
- 新出现的字段类型先提出；获准维护索引时才追加为「候选新字段」，不擅自扩页。

## 结束报告（三行）

- 填了哪几页、哪几段。
- 剩几个空白、哪个最挡事。
- 有无 ⚠ 待裁决。

## 别用它的时候

- 问题本身是低代价可逆的事：直接做，不采访。
- 本人只是在倾倒或倾诉：先回应，问一句要不要建档；不主动开题。
- 事实库已经有答案：引用并问「还对吗」，不重问。
