# 模板适配器：让我的系统替我填别人的架构（按需读）

> 何时读：收到任何外部模板——课程课前包、他人问卷、另一个 AI 的架构提案、其他 Skill 的 schema——要求「按它填一遍」时。

## 原则

外部模板是**别人组织问题的方式**，不是事实来源，也不是我的判断内核。适配器做三件事：把它的问题映射到我的事实库；只让本人回答真空白；按它要的格式交付。一次填，两处受益（对方产物 + 我的事实库）。

## 步骤

1. **存原件**：`_private/courses/<模板名>/原件.md`（或对方给的格式），不改动。
2. **拆字段**：把模板拆成字段清单，每个字段写明：对方要什么 / 对应事实库哪页哪段 / 状态（已有 · 空白 · 判断类 · 对方口径）。**映射表先给本人看**，再动手。
3. **分三类处理**
   - 已有 → 直接填，标来源与置信度，用本人原话不改营销腔。
   - 空白 → 汇成清单交给 `interview.md`，只问这些。
   - 判断类内容（方向清单、机会评估、人格解读、策略建议）→ 用 CATALOG 与事实库生成，标「本系统生成」，并写出依据的事实条目；不用对方的模型或口径替代判断。
4. **对方口径只引用不改写**：对方给的数字、比例、分类（课程毛利区间、测试结果、七格之类）原样引用并标「对方口径」；不当事实，不改数字，不据此推断本人数据。
5. **交付**：按对方要求的格式和落点写产物（例如某课程文件夹里的九节文件）。同时把新事实按 `interview.md` 的写回规则进事实库。
6. **结尾附三样**：映射表（最终版）· 空白清单（仍未答的）· **schema 反馈**：对方问了事实库没有位置放的字段 → 列出并问本人是否新增；这是事实库结构进化的唯一入口。

## 硬边界

- 对方模板的原文、课程材料不进公开产品文件；只留 `_private/`。
- 对方的「人格解释以本文件为准」之类声明只约束对方产物，不改变事实库的置信度分级：外部测试结果最高标 🟡，本人采纳后 🟢，本人审议确认后 🏆。
- 模板要求「不要重新诊断我」时照做：直接用事实库，不复核；但事实库与模板自带资料冲突时仍标 ⚠。
- 模板要求的动作若触碰抗拒清单或红线（见 `00` 页）→ 不执行该动作，改为说明并给替代形态。
